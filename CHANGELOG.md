## [0.9.1](https://github.com/helmut-hoffer-von-ankershoffen/heinzel/releases/tag/v0.9.1) - 2026-10-29

Plugins now own complete features across CLI, API, MCP and UI through public extension contracts, including menu priorities, Today widgets, notifications and soundscapes. Standard installations include Clock, Resource, Tailscale and the Heinzelmännchen theme; sharing and playback require an explicit choice.

Authors get minimal and rich scaffolds, matching human and agent guides for public or private repositories, and one independently released toolkit for owning checks, builds, preview, installed-wheel acceptance and immutable publication. Plugin-only work completes its cycle without running Core's suite.

This is a breaking plugin boundary. Start with a fresh installation and configuration.

GitHub, Atlassian, Google Workspace (Docs, Sheets, Drive, Calendar, Gmail), Zoom (from its summary emails) and mail are first-party plugins that work as an ordinary employee through gh, acli and gws. ## [0.2.0](https://github.com/helmut-hoffer-von-ankershoffen/heinzel/releases/tag/v0.2.0) - 2026-10-24

Heinzelmännchen now works for you while you're away. A daemon on your machine runs jobs on a schedule and leaves
a receipt for every run; workflow contracts, Markdown files with frontmatter, compile to those jobs. Modules declare
the capabilities they need (`tracker:read`, `documents:read,write`) and configuration binds adapters to them; agent
runners for Claude Code and any command-line agent draft the results. Credentials live in the OS keychain, `hz` tells
you when a newer release exists, and nothing is sent home. Adapters for GitHub and Atlassian ship as plugins.
