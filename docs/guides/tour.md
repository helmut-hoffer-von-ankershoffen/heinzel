# Product tour

Real screens from the released app, captured with fictional ACME data in a disposable profile. Swipe each strip for a
zoomed detail and a dark view, and select an image to inspect it.

## See what feeds the next piece of work.

The workflow graph shows the systems you connected, the assets found through them, a contract and the output it
maintains.

![A real workflow graph, populated from fictional local sources and contract declarations.](../assets/tour/graph-overview.png)
<!-- /hz:tour-story -->

## Keep useful commands beside the work.

The terminal opens beside the page you are on, with a tab for each command. On a phone, use the scrollable key row
for Escape, Tab, Ctrl+C, Ctrl+Z, Ctrl+D and the arrow keys.

<!-- hz:tour-story terminal -->
![Two terminal tabs in the local demo: hz graph and hz drafts, beside the contract.](../assets/tour/terminal-tabs.png)
<!-- /hz:tour-story -->

## Ask here. Review the action before it runs.

Every chat is with one of your Heinzels, beside every screen. "Ask" on a card puts the question in its message
field for you to read and send. When it proposes a change, you see the exact command first. This demo uses a scripted
local runner: no model is called. The picture is from an earlier release, before every chat was with a Heinzel; the
proposal and its approval look the same.

<!-- hz:tour-story chat -->
![The chat's approval flow in an earlier release, with a scripted local demo runner; no model call.](../assets/tour/chat-proposal.png)
<!-- /hz:tour-story -->
