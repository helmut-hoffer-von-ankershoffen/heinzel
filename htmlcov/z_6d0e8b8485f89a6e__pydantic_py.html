1"""The `pydantic-ai` option: a model API reached through Pydantic AI, with a key (ADR 0050, 0057). 

2 

3Three kinds of API, by configuration in `[ai.access]`: 

4 

5- a vendor's own API: `model = "anthropic:claude-sonnet-4-5"` or `"openai:gpt-5"`, as Pydantic AI names it; 

6- an OpenAI-compatible endpoint: `base_url = "http://localhost:11434/v1"` (Ollama), LM Studio, vLLM or OpenRouter, 

7 with `model` the name the endpoint knows (`llama3.1:8b`); the key is optional; 

8- (with a ChatGPT login, a follow-up.) 

9 

10The key is the credential `ai.access/api-key` in the keychain (`hz system credential set ai.access api-key`) or the 

11vendor's own variable, e.g. `ANTHROPIC_API_KEY`; it goes only over https, or over http to this machine. The vendor's 

12client comes with an extra (`heinzel[anthropic]`, `heinzel[openai]`; endpoints use OpenAI's); the core itself imports 

13only `pydantic_ai`, never a vendor SDK. `status` reads configuration and the last listing only. `test` lists the 

14models the API offers (kept for the picker) and sends one short request, capped at one request and a few tokens. 

15"""
