1"""The team module: create, join and add to the Git repository a team keeps its shared state in. 

2 

3A team repository holds the manifest `hz.yaml`, the roster `team/roster.yaml` its owners approve, each person's 

4`people/<handle>.yaml`, the team's contracts in `workflows/`, `inventory/`, `policies/` and a GitHub Actions workflow 

5that checks them (proposed onboarding ADR). The invite is the repository's URL: `hz team join <url>` clones it with 

6your own access, finds you in the roster by the login you are signed in with, and makes it your team. The module 

7provides the `OrgContext` other modules read it through (`workflow` finds `team:` contracts there). 

8 

9Steps that change something outside your machine (creating a repository, pushing, opening a pull request) and 

10making a team yours wait for `--yes`; until then they are shown. These operations are CLI and MCP only: a web page can 

11reach a local REST server (ADR 0019). 

12"""

115@module.health 

116def health(service: TeamService) -> list[Check]: 

117 """The team repository's checkout exists and its manifest and roster are valid.""" 

118 if service.checkout is None: 

119 return [] 

120 shown = service.show() 

121 if shown.problems: 

122 fix = shown.next[0] if shown.next else "fix the file in a pull request to the team repository: hz team show" 

123 return [Check(name="checkout", status=Status.DOWN, detail=shown.problems[0], fix=fix)] 

124 return [Check(name="checkout", status=Status.UP, detail=f"{shown.name}, {len(shown.members)} member(s)")]
